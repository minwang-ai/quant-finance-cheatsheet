# [set](https://docs.python.org/3/library/stdtypes.html#set)

## Characteristics & Definition
data structure for a collection of values that allows us to **eliminate duplicates**.

| Feature | Description |
| :--- | :--- |
| **Container** |  **unordered, mutable (changeable)** collection of values|
| **Mutable (changeable)** | We can modify, add, or remove items after creation  |
| **Unique**| **No duplicates** |
| **Element Types** |  |
| **Creation Syntax** | `my_set= set()`|
| **When to Use Set** | - When we want to make sure there is no duplicates <br> - When the value should be able to be changed   |
