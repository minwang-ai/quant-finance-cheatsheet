    Libraries¶

    Course source: CS50P Lecture 04

    Instead of copying and pasting code from an old project of yours or others, you can share functions or features by creating modules and import modules/functions to your new project.

    Import Functions, Classes, Variables¶

    keywords Purpose Syntpurposeax Notes Pros and Cons When to Use
    import (preferred) import the entire module (all the functions, classes, variables) into the current namespace import <module>
    optional:
    import <module> as <alias>    		 When we call the functions, we need to specify the module name as a prefix module.function() + Clarify the origin of names of functions and variables to the module. Keep namespace clean, as it prevents potential naming conflicts.
    + Avoid ImportError in case of circular imports

    - Calling multiple times of module.function makes the code longer, ugly and annoying    		 - not use the functions/classes/variables frequently
    - want to clarify the origin of names
    from ... import ... Case 1. only import some specific functions/classes/variables of a module into the current namespace

    Case 2. import submodules    		 from <module> import <function>,<class>, <variable>

    from <module> import <submodule>    		 When we call the functions, we simply call the function function() without specifying the module name as a prefix

    Note:
    Avoid using from <module> import * because they make it unclear which names are present in the namespace (hide the origin of names, and risk overwriting built-in functions), confusing both readers and many automated tools.    		 - Without the module prefix leads to cleaner code when using that function multiple times
    - We cannot use the same name for the variable or functions name as the one from the libraries, otherwise cause potential naming conflicts.    		 - Use a name frequently
    - The module name is long

    Note:

    • Both methods load the entire module.
    • Group Imports Logically:
      • Standard library imports (e.g., import os).
      • Third-party imports (e.g., import requests).
      • Local/application-specific imports (e.g., from mypackage import utils).

    Command-Line Arguments: sys & argparse¶

    sys¶

    The sys is a module that allows us to take user input from the command line when we automate running Python scripts quickly.

    Variable Purpose Syntax Parameters (as input) Return Value Example/Notes
    sys.argv
    stands for argument vector    		 Access a list of all the arguments that user typed at the command line as inputs to the program when running python script to influence the behavior of the program. sys.argv[i] i (index): An integer representing the position of the argument in the list. str - sys.argv[0] is always the python file_name.py
    - sys.argv[1] is the first user input. Using slicing sys.argv[1:] to skip the file name.

    Packages & APIs: requests & json¶

    Third-party packages (installed via package manager pip install package_name) allow us to interact with external data and functionalities. PyPI is a repository or directory of all available third-party packages currently available.

    APIs (application program interfaces) refer to third-party services that we can write code to connect to download and access data. requests is a package that allows our program to make internet request using python code behave as a web browser. We can constructe URL by reading the API documentation we request.

    The format in the downloaded text file is called JSON (javascript object notation) , a language agnostic text-based format that is used to exchange text-based data between applications. Python has a built-in json library that can help us interpret the data received.

    Method Purpose Syntax Parameter Return Value
    requests.get() Download data from a URL and store it into response object, like typing url in a web browser and enter. response = requests.get(url) url: The https url to the API in string format. Check the documentation of the API. Response object
    response.json() Converts that JSON response into a Python dictionary so that we can extract specific information content = response.json() dict or list
    json.dumps() Format JSON data for nice printing. json.dumps(obj, indent=2) - obj
    - indent: Indentation making nested data more readable.    		 str

    Best practice: using try-except block for requests:

    get.py 

    import requests

def get_item(query):
    payload = {'key1': 'value1', 'key2': ['value2', 'value3']}
    try:
        response = requests.get(
            "https_url",
            params = payload
        )
        response.raise_for_status()  # will raise an HTTPError if the HTTP request returned an unsuccessful status code.
    except requests.RequestException:
        print("Couldnt complete request!")
        return []

    content = response.json()
    return [item["key"] for item in content["data"]]

    PDF Generation (fpdf2)¶

    The FPDF class is the primary engine for creating and exporting PDF documents.

    The canvas uses a standard 2D millimeter-based coordinate system

    • Origin \((0,0)\): Located at the top-left corner of the PDF page
    • \(X\)-Axis (Horizontal): Measures distance from the left edge (\(0\text{ mm}\)) to the right edge (\(210\text{ mm}\)).
    • \(Y\)-Axis (Vertical): Measures distance from the top edge (\(0\text{ mm}\)) down to the bottom edge (\(297\text{ mm}\)).
    • Internal Cursor: fpdf2 maintains an internal drawing cursor \((x, y)\) that tracks where the next text or image will be placed automatically unless we override it.
    Method / Constructor Purpose Syntax Example Parameters / Options Return Value / Behavior
    FPDF() Constructor Instantiates a new PDF document object with page dimensions and units. pdf = FPDF(orientation="P", unit="mm", format="A4") - orientation: "P" (Portrait) or "L" (Landscape) or "Letter", Legal.
    - unit: Measure unit ("mm", "cm", "pt", "in").
    - format: Standard page sizes ("A4" = 210x297mm).    		 Returns a new FPDF instance.
    pdf.add_page() Adds a new blank page to the PDF document.

    The origin is at the upper-left corner and the current position is by default placed at 1 cm from the borders; the margins can be changed with set_margins.    		 pdf.add_page() None. Appends a page
    pdf.set_font() Before we can print text, it is mandatory, otherwise the document would be invalid. pdf.set_font("helvetica", style="B", size=30) - family: Built-in fonts ("helvetica", "times", "courier", Symbol and ZapfDingbats).
    - style: "" (Regular), "B" (Bold), "I" (Italic), "U" (Underline).
    - size: Font size in points (pt).    		 Updates active document font settings.
    pdf.set_text_color() Sets the foreground text color using RGB or grayscale values. pdf.set_text_color(255, 255, 255) - RGB: Three integers (0–255) for Red, Green, Blue (e.g., 255, 255, 255 for white).
    - Grayscale: Single integer (0–255).    		 Changes active text color.
    pdf.cell() Renders a rectangular block of text at the current cursor position. pdf.cell(w=0, h=10, text="string text", new_x= , new_y="NEXT", align="C") - w: Cell width (0 stretches cell across entire printable width).
    - h: Cell height in mm (negative height moves cursor upward).
    - new_x: New current position in x after the call.
    - new_y: Set to "NEXT" to automatically advance cursor to next line. -
    center (bool): center the cell horizontally on the page.
    - align: "C" (Center), "L" (Left), "R" (Right), "X:(center around current x position)    		 Draws text cell on the page.
    pdf.image() Embeds an image (PNG/JPEG) onto the page. pdf.image("image.png", x="C", y=, w=width) - name: Path to image file.
    - x: Horizontal coordinate or "C" (Center horizontally).
    - y: Vertical coordinate in mm (omitting y uses current cursor position).
    - w: Target width in mm (height h scales automatically).    		 Renders image on the PDF canvas.
    pdf.set_y() Sets the vertical position of the cursor explicitly. pdf.set_y(140) y: Absolute vertical position in mm (positive value measured from top edge; negative value measured from bottom). Moves active drawing cursor vertically.
    pdf.epw (Property) Gets the Effective Page Width (total width minus left and right margins). w = pdf.epw None (read-only property). Returns float representing printable width in mm.
    pdf.output() Compiles and writes the PDF data to a file on disk. pdf.output("file_name.pdf") name: Destination filename or file path string. Saves the generated PDF file to disk.
