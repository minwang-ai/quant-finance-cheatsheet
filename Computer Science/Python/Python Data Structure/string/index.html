    String (str)¶

    String Operator Overloading¶

    Syntax Application Example
    Concatenation (+) chain strings together. str1 + str2
    *multiplicaton () repeat strings n times print(str_variable * n)

    Output Formatting (f-strings)¶

    prefixing a string with f, expressions inside {} are evaluated at runtime, making it simple to embed variable values and expressions directly within string literals.

    f"{value:format}"

    Parts Meaning
    value The variable or expression we want to print.
    colon : The separator that tells Python everything after this is a formatting instruction.
    format Special codes that tell Python how to display that value.

    f-strings Patterns Cheat Sheet¶

    Feature Meaning Syntax Examples
    Interpolation Inject variables into strings. f"other_text, {variable_name or expression}"
    Thousands Formate large number variable num with commas , f"{num:,}" print(f"{num:,}")
    1000000 -> 1,000,000
    Precision round the output variable num to the nearest n decimal points. Here n is a number and it could not be 0. f"{num:.nf}" print(f"{num:.2f}")
    3.1415926 -> 3.14
    Percentage automatically convert float output variable num to percentage, add %sign and keep the nearest n decimal points. f"{num:.n%}" f"{num:.0%}"
    0.75 -> "75%"
    Padding Pad or fill a string with the specified padding character pad_char to a specific total width total_width: - Center the string and pad both sides using ^:
    f"{str:{pad_char}^total_width}"
    - Padding from the right using <:
    f"{str:{pad_char}<total_width}"
    - Padding from the" left using >:
    f"{str:{pad_char}>total_width}" - zero-padding for numbers: f"{num:0total_width}"    		 - f"{str:{pad_char}^{width}}" string "GFG" pad with character "-" becomes "----GFG-----"
    - zero-padding: f"{num:02}" "9" becomes "09"
